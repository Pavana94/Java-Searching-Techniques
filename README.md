# Java Searching Techniques 🔍

This repository contains basic searching techniques implemented in Java.

## 📌 Searching Techniques

### 1. Linear Search

Linear Search checks each element one by one until the required element is found.

- Works with sorted and unsorted arrays
- Easy to understand and implement
- Time Complexity: O(n)

### 2. Binary Search

Binary Search searches for an element by repeatedly dividing the array into two halves.

- The array must be sorted
- This program uses Arrays.sort() before searching
- Time Complexity: O(log n)
